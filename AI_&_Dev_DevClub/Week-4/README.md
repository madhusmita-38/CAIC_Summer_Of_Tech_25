# CAIC WEEK 4 - AI+DEV project
An AI tool that generates tweets and predicts likes using a Flask backend and a Streamlit UI.

## Tech Stack
- **Frontend**: Streamlit
- **Backend**: Flask
- **Model**: Pre-trained `.pkl` like predictor

## Features
- Choose tweet type, message, topic
- Customize tweet metadata (time, media, etc.)
- Get generated tweet + predicted like count

## What I did (Overview)
- Built a frontend using streamlit
- Connected the frontend to my existing APIs
- Collected input from the user (like company, message, tweet_type, etc.)
- Displayed the generated tweet and predicted likes
- Make the app interactive and easy to test
